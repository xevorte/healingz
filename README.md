# Healingz

Aplikasi Flutter sederhana untuk menampilkan kategori dan destinasi wisata.

Struktur `lib/`:

- `main.dart` dan `app.dart`: titik awal dan konfigurasi aplikasi.
- `app_theme.dart`: warna dan tema.
- `models/`: bentuk data kategori dan destinasi.
- `services/`: permintaan ke API kategori dan destinasi.
- `pages/`: Onboarding, Home, detail destinasi, dan booking.
- `widgets/`: widget yang bisa dipakai ulang.

Jalankan dengan `flutter run`. Rapikan kode dengan `dart format lib` dan periksa dengan `flutter analyze`.
